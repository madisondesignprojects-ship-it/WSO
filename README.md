# West Star Organics website refresh

Responsive, static HTML/CSS/JavaScript refresh for West Star Organics.

## Files
- `index.html` — page structure and business content
- `styles.css` — responsive visual system in the existing forest-green, leaf-green, sage and warm-paper palette
- `script.js` — mobile navigation and contact-form behavior

## Notes
- No build step or package installation is required.
- The contact form opens the visitor's email application with a prepared message to info@weststarorganics.com. It does not send directly from the website.
- The logo, photography and certification marks are currently referenced from the existing WordPress website. Before pointing the weststarorganics.com domain at a new host or retiring the old WordPress hosting, copy these assets into this repository and update their paths so they continue to load.
- Seasonal hours and the 2026 plant-variety PDF were carried forward from the supplied website content. Refresh these for the 2027 season when West Star publishes updated information.
